Patch Release for STM32CubeMP2 Firmware Package V1.3.1 / 03-June-2026

Main Changes

v1.3.1 release

  • Firmware update is now supported for STM32CubeMP2 M33TDCID Boot configuration.
  • Low Power management support is expanded. Shutdown is now supported
  • StarterApp (M33 NonSecure application manager) is updated.
    • It now handles Low power state transitions and management.
    • A new FreeRTOS Low Power management task added to process the system requests for low power transitions and interfaces with appropriate TFM API calls.
    • RPMsg requests (coming from Cortex-A35) are now supported to configure low power states.
  • Template StarterApp is updated for low power management.
  • Utility M33TD_NSAppCore is updated for low power and firmware update management.
  • PWR HAL is updated to add DSB before WFI in low power functions.
  • Bugfix for CMSIS Device headers to correct malformed comment delimiters and missing opening parenthesis for some definitions.
  • Miscellaneous bug fixes.
